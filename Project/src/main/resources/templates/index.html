Подключение к базе данных

Для просмотра и управления базой данных используйте H2 Console:

  1. Откройте http://localhost:8080/h2-console
  2. Настройки подключения:
    • JDBC URL: jdbc:h2:mem:testdb
    • User Name: sa
    • Password: (оставьте пустым)
  3. Нажмите Connect для подключения

После подключения выполните запрос SELECT * FROM VEGETABLE; для просмотра данных.
